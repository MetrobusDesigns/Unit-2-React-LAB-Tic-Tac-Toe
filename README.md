# Tic Tac Toe

## Overview

In this project, you will build a simple **Tic Tac Toe** game using React. Two players will take turns placing X's and O's on a 3x3 board. The game should:

- Track whose turn it is  
- Detect a winner  
- Detect a draw  
- Allow the game to be reset  

---

## Tasks

### 1. Board

- Display a 3x3 grid  
- Clicking a square places the current player's mark  

### 2. Player Turn

- Track whose turn it is (X goes first)  
- Alternate turns after each move  

### 3. Winner

- Detect when a player has won  
- Display the winner  

### 4. Draw

- Detect when all squares are filled with no winner  
- Display `"DRAW"` if the game ends in a draw  

### 5. Reset

- Add a button that resets the board  
- Reset player turns and move count  

---

## Requirements

- Use **React state** to track board, turns, and moves  
- Use **event handling** for clicks on squares and reset button  
- Use **conditional rendering** to show winner, draw, and next player  

---

## Stretch Goals

- Highlight the winning line  
- Add a scoreboard for multiple rounds  
- Keep track of move history and allow the user to undo a move
- Add additional styling!
